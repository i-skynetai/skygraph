# Code of conduct

Skygraph is a small project, and it stays pleasant to work on by a few plain rules.

- **Be kind and assume good faith.** Disagree with ideas, never with people. Critique a
  change by what it does, with evidence — a test, a file and line, a measurement.
- **No harassment of any kind.** That includes insults, personal or political attacks,
  unwanted attention, and publishing anyone's private information.
- **Keep it on topic.** Issues and pull requests are for the code, the docs and how the
  project is used.

**Reporting.** If someone's behaviour worries you, contact the maintainer privately
through the address on the maintainer's GitHub profile, or open a private security
advisory if the matter is sensitive. Reports are read in confidence.

**What happens.** The maintainer may remove comments, close threads, or block anyone
who does not follow these rules, in this repository and its discussions.

This page is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
